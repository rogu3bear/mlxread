# Contributing to MLXRead

MLXRead is open source (MIT). This doc covers building from source, signing,
and the security-sensitive areas to be careful with.

## Build from source

```bash
brew install xcodegen
xcodegen generate
script/build_and_run.sh          # build + launch
script/test.sh                   # unit tests (no network, no models)
```

The Xcode project is generated from `project.yml` — edit that, not the
`.xcodeproj`, and re-run `xcodegen generate`. Plain `swift build` is not
supported (mlx-swift's Metal kernels need the Xcode build system).

## Signing

`project.yml` defaults `DEVELOPMENT_TEAM` to the maintainer's team. Override
it without touching tracked files:

```bash
DEVELOPMENT_TEAM=YOURTEAMID script/build_and_run.sh   # your Apple team
CODE_SIGNING_ALLOWED=NO      script/build_and_run.sh   # quick unsigned build
```

Prefer a **stable** signing identity while developing: the macOS Accessibility
(TCC) grant is keyed to the code signature, so ad-hoc/unsigned rebuilds make
macOS re-prompt for Accessibility every time. With a stable Apple Development
identity, the grant persists across rebuilds.

Debug builds keep hardened runtime off (needed for the debugger and XCTest
injection). Release builds enable hardened runtime — required for notarization
and, with a Developer ID signature, for stripping `get-task-allow`.

## Releases and auto-update

See [docs/updates.md](docs/updates.md). The Sparkle EdDSA **private key is a
maintainer-owned credential** — it lives in the maintainer's Keychain, is
never committed, and is never generated by CI. `.gitignore` excludes `*.pem`
and `sparkle_private_key*`.

## Security-sensitive areas

Changes to these deserve extra review (see `mlxread-threat-model.md`):

- **`MLXRead/Hotkey/GlobalHotkeyService.swift`** — the global event tap sees
  every keystroke; keep the callback O(1) and never log key contents.
- **`MLXRead/Accessibility/`** — selection capture. Never log selected text
  (`AppLogger` uses counts/`<private>` only). The clipboard fallback must keep
  its changeCount-guarded restore.
- **`MLXRead/Models/ModelStore.swift`** — model download. Keep it HTTPS; treat
  any change to validation/integrity carefully.
- **`MLXRead/Updates/UpdateService.swift`** + Info.plist `SUFeedURL`/
  `SUPublicEDKey` — update integrity. The feed must stay HTTPS and signed.
- **`project.yml`** entitlements/hardened-runtime settings.

## Privacy invariants (do not regress)

- Selected text stays in memory only, is never written to disk, and is never
  logged. See [docs/privacy.md](docs/privacy.md).
- No analytics, no crash-reporting SDK, no network except explicit model
  download and the signed update check.

## Tests

Add unit tests for logic changes (`MLXReadTests/`). Integration tests that hit
real models are opt-in (`script/test.sh --integration`). Run `script/test.sh`
before opening a PR.
