Design boundaries and source owners
  • Voice Preview auditions without changing the reading voice. Use selects it.
  • Models Use & Preview selects the model and plays a sample, preserving the existing effect.
  • A static menu-bar warning makes unavailable actions discoverable. A dead shortcut cannot receive a request.
  • Recovery opens the existing destination and focuses the relevant control; it never replays selected text automatically.
  • Voice catalogs are representative fixtures. Existing language filters and the remaining menu commands are retained outside this focused study.
  • The HTML study demonstrates layout and proposed transitions. Native focus, Accessibility, event taps, audio, and runtime races still need separate verification after the app resumes.
